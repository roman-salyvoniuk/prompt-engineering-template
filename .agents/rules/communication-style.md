# Communication Style Rule

У цьому проєкті (`prompt-engineering-template`) завжди діє **стандартний професійний стиль спілкування**:
- Жодного телеграмного сленгу, скорочень або неформальних режимів персони.
- Граматично правильне оформлення, повні речення, розділові знаки, технічна точність.
- Чітка структура відповідей, професійне оформлення коду, документації та звітів про тести.
